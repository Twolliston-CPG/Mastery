# Progress log

> One row per week, written on Sunday. The column that matters is **what surprised me**: surprise
> is where your model was wrong, and by week 26 these cells are the honest record of what you
> learned. Lives at `~/mastery/progress/progress.md`; copied from `_shared/templates/`.

## Weekly rows

| 1 | Linux I, Git | n · link | — | 0 | 1.1 ok | |
| 2 | | | | | | |
| 3 | | | | | 3.1 ok · 1.1 slipped at ④ | |

- **Deliverable shipped** — `y`/`n` and the repo link. "Nearly" is `n`.
- **Gate** — `—`, `pass`, or `fail: <the criterion, in one sentence>`. Only gate weeks (4, 9, 13, 17, 21, 26, and 30 if taking the CKA module).
- **Hours** — actually logged, not planned. This number predicts everything else.
- **Figures redrawn** — the figures you redrew from memory this week and the badge where the order
  slipped: this week's on Friday, the one from two weeks ago on Sunday, every figure since the last
  gate on a gate Sunday. Schedule in `curriculum/FIGURES.md`.
- **What surprised me** — one sentence. Where a word stood in for a mechanism.

## Monthly retrospective (gate weeks: 4, 9, 13, 17, 21, 26, and 30 for the CKA module)

Copy this block under the gate week's row and fill it in. The format matches the bottom of each
gate's `assessment.md`.

1. **Hours actually logged** vs the 4–8/day target.
2. **The 70/30 ratio** — the fraction of time that was hands-on keyboard.
3. **Top 3 "Surprised" lines** from `incident-journal.md`. These are your interview stories.
4. **Weakest area**, and the specific thing you will do about it next month.
5. **Sustainability** — a rest day every week? If not, fix that before the next week starts.
6. **Figures redrawn cold** — every figure since the last gate, with the badge where it slipped.
   A figure you cannot redraw at the gate is the criterion you will fail next.
7. **Kubernetes ladder scored** (from Gate 4) — the thirteen-topic table from `KUBERNETES-MASTERY.md` §6,
   with evidence per rung and the topic that has not moved in two scorings.
